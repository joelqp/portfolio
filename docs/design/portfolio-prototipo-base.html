Primera experiencia · 03
AIA
Prácticas de data scientist · SQL, preprocesamiento y cartografía
Jul — Sep 2023

        
Mi contribución
Vistas SQL complejas, preprocesamiento y búsqueda de cartografía descargable para un proyecto relacionado con rutas de camiones.
No desarrollé el modelo original. Los algoritmos y las reglas de materiales de esta demo son una nueva recreación personal.
Experiencia profesionalSQL · Datos · Cartografía
Objetivo de la demoConvertir dos lotes de restos en material reutilizable, abastecer dos fábricas y volver a la base con la menor distancia.
Detalle técnico · Métodos y supuestos
Un camión, dos materiales y cuatro visitas. Cada procesador cambia un lote de restos por uno reutilizable. Cada fábrica recibe uno reutilizable. El método exacto comprueba todos los órdenes válidos; la optimalidad se limita a esta red ficticia y estas reglas.
